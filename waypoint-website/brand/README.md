# Waypoint Search Group — brand kit

| File | Use it for |
|---|---|
| `logo.svg` / `logo.png` | Main logo on white or light backgrounds: documents, proposals, email signatures |
| `logo-white.svg` / `logo-white.png` | Logo on dark backgrounds |
| `logo-stacked.svg` | Square-ish spaces: event signage, social posts |
| `logo-mark.svg` | The symbol on its own: favicons, small spaces |
| `logo-square.png` | **LinkedIn company page logo** (400 × 400) and other profile pictures |
| `linkedin-banner.png` | **LinkedIn company page cover image** (1584 × 396) |
| `og-image.png` | The preview image when the website is shared (1200 × 630) |

Colours: navy `#0A1B2B`, signal orange `#F26A21`, steel `#4E6B86`.
Fonts: Archivo (headings) and IBM Plex Mono (labels), both free from Google Fonts.

The SVG logos have their text converted to outlines, so they look the same everywhere and need no fonts installed.
